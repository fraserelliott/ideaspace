# IdeaSpace

# Development server

IdeaSpace uses a separately hosted API for authentication, image handling and IdeaSpace data. The included development script assumes the server repository is available at ../react-portfolio/backend. If your server is located elsewhere, update this path in package.json, or start the server separately before running the frontend.

The server it uses is available in the backend folder at https://github.com/fraserelliott/react-portfolio/
